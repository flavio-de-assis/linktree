## 🎯 Objetivo do Projeto

Este projeto tem como objetivo criar uma página simples, responsiva e profissional para:

- Centralizar links importantes (LinkedIn, GitHub, Portfólio e Currículo)
- Apresentar meu posicionamento profissional em **Engenharia de Dados**
- Servir como cartão de visita digital para recrutadores e networking

---

## 🧠 Sobre Mim

Sou Analista de Suporte com atuação em dados e em transição para Engenharia de Dados, com foco em:

- Construção de pipelines de dados (ETL)
- Consultas SQL
- Automação e tratamento de dados com Python

Atualmente, aplico esses conhecimentos em projetos práticos voltados para Engenharia de Dados.


---

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estrutura da página  
- **CSS3** — Estilização e layout responsivo  
- **Google Fonts (Montserrat)** — Tipografia  
- **GitHub Pages** — Deploy do projeto  

---

## 🎨 Principais Funcionalidades

- Layout responsivo e minimalista  
- Links centralizados para canais profissionais  
- Estilo dark com foco em legibilidade  
- Remoção de estilos padrão de links (ex: cor roxa de links visitados)  
- Ícones padronizados e alinhados
